# 운영자 사진 폴더

여기에 숙소 사진(jpg · png · webp)을 넣고 푸시하면, 다음 제작(`mode: "veo"`)에서 쿠팡 사진보다 **먼저** 씁니다.
쿠팡 사진은 객실 위주라 물놀이 공간·산책로 사진이 모자랄 때 채우는 용도입니다.

- 권장 구성: 물놀이 공간 3장 · 객실 내부 2장 · 특별한 공간(산책로·정원·테라스 등) 2장. 분류는 프로그램이 사진을 보고 자동으로 합니다.
- 저작권: **숙소에서 사용을 허락받은 사진만** 넣습니다. 홈페이지·예약 사이트 화면 캡처는 넣지 않습니다 (CLAUDE.md 규칙).
- 이 저장소는 공개입니다. 여기 넣은 사진은 누구나 볼 수 있습니다.
- 한 숙소 제작이 끝나면 다음 숙소를 위해 사진을 지우거나 바꿉니다 (남겨 두면 다음 숙소 영상에 섞여 들어갑니다).
