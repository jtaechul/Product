# AI 숏폼 동화 스튜디오

주제 한 줄로 한국 전래동화 쇼츠(9:16)를 반자동 제작한다. 휴대폰만으로 조작한다.

```
관리자 페이지에서 주제 입력
  → GitHub Actions가 대본 + 씬별 영상 프롬프트 생성
  → (프롬프트를 복사해 Runway·Pika 등에서 씬 영상 제작)
  → 관리자 페이지에서 씬 영상 업로드
  → GitHub Actions가 나레이션 + 가라오케 자막 입혀 최종 MP4
  → 관리자 페이지에서 바로 재생·다운로드
```

무료다. 화면은 Cloudflare Workers, 무거운 영상 작업은 GitHub Actions, 파일 보관은
GitHub Release가 맡는다. 저장소의 `book-carousel`·`verdict-theater`와 같은 구조다.

## 구조

```
shorts_studio/
├── admin/                  관리자 페이지 (Cloudflare Workers)
│   ├── public/index.html   모바일 UI — 인물기준이미지·프롬프트복사·영상업로드·재생
│   └── worker/index.mjs    로그인·GitHub 호출·업로드 중계·완성본 재생
├── core/                   제작 엔진 (Actions와 로컬이 공유)
│   ├── llm.py              줄거리 → 씬 대본 + 툴별 영문 프롬프트 (Gemini)
│   ├── tts.py              Gemini TTS 합성 + 줄 단위 실측 타이밍
│   ├── subtitle.py         가라오케 ASS 자막
│   └── video.py            FFmpeg 규격변환·합성·자막번인
├── content/<id>.json       작품 기록 (대본·상태·완성본 주소) — Actions가 커밋
├── run_script.py           ① 주제 → 대본
├── run_render.py           ② 영상 + 대본 → 최종 MP4
└── app.py                  (선택) 로컬 PC에서 쓰는 Streamlit 단독 실행판
```

워크플로: `.github/workflows/shorts-studio-script.yml` · `shorts-studio-render.yml` ·
`deploy-shorts-studio-admin.yml`

## 처음 한 번만 하는 준비

| 이름 | 쓰임 |
|---|---|
| `GEMINI_API_KEY` | 대본 생성 + 성우(TTS) |
| `CF_API_TOKEN` | 관리자 페이지 배포 |
| `CLOUDFLARE_ACCOUNT_ID` | 어느 Cloudflare 계정에 올릴지 |
| `MOVIEGEN_ADMIN_PASSWORD` | 관리자 페이지 로그인 비밀번호 |
| `MOVIEGEN_ADMIN_GH_TOKEN` | 워커가 쓸 GitHub 토큰 (Contents·Actions 모두 Read and write) |
| `MOVIEGEN_SESSION_SECRET` | (선택) 로그인 위조 방지용 |

손님은 관리자 페이지 주소를 열고 비밀번호만 치면 된다. 토큰은 워커 안에만 있다.

## 설계 메모

**⭐ 가라오케 자막을 맞추는 법 — 줄 하나가 곧 합성 단위.**
나레이션은 Gemini TTS로 만든다(감정·억양을 자연어로 지시할 수 있어 성우처럼 읽는다).
그런데 Gemini TTS는 "몇 초에 어떤 말을 했는지"를 알려주지 않는다. 그래서 **자막 한 줄을
통째로 하나의 합성 단위로 삼는다**: 줄마다 따로 합성하고, 앞뒤 묵음을 잘라내고, 실제 길이를
샘플 수로 정확히 잰 뒤, 우리가 정한 쉼(문장 끝 0.32초·쉼표 0.18초·줄바꿈 0.06초)을 끼워
이어 붙인다. 줄이 화면에 뜨고 사라지는 시각은 **추정이 아니라 실측**이라 어긋날 수가 없다.
한 줄(13자 안팎) 안에서 어절별 하이라이트만 음절 수 비례로 나누므로 오차는 수십 밀리초다.
받아쓰기(STT)로 되짚는 방식이 필요 없고, 한국어 오인식도 없다.

예비 엔진으로 Edge-TTS(`engine=edge`)를 남겨 두었다. 감정 지시는 못 하지만 단어
타임스탬프(`WordBoundary`)를 엔진이 직접 주고 호출이 한 번이라 빠르다.
(로직 출처: `short-movie-generator/src/core/narration_sync.py`)

**연기 지시는 씬마다 다르게 붙는다.** 대본을 만들 때 씬마다 `voice_direction`
("숨을 죽이고 낮게, 한 박자 느리게" 같은 한 줄)을 같이 뽑아, 합성할 때 그대로 전달한다.
전부 같은 톤으로 읽으면 로봇처럼 들린다.

**대본은 두 단계로 만든다.** 먼저 줄거리(발단·전개·위기·절정·결말)와 등장인물을 통째로
설계하고, 그 다음에 그것을 씬으로 쪼갠다. 한 번에 시키면 모델이 앞뒤를 안 보고 씬을 하나씩
지어내어 이야기가 끊긴다. 각 씬은 앞 씬에서 무엇을 물려받아 다음으로 무엇을 넘기는지
(`continuity`)를 적게 해 컷이 따로 놀지 않게 한다.

**나레이션은 씬별로 따로 만든다.** 씬 영상 길이를 그 씬의 나레이션 길이에 정확히 맞추기
위해서다. 전체를 한 덩어리로 만들면 말과 화면이 뒤로 갈수록 밀린다.

**⭐ 인물 일관성 — 이 프로젝트에서 가장 중요한 설계.**
씬마다 영상 AI가 따로 그리면 주인공이 컷마다 다른 사람이 된다. 유일하게 확실한 해법은
**인물마다 기준 이미지 한 장**을 만들어 그 인물이 나오는 모든 씬에 함께 넣는 것이다
(image-to-video). 등장인물은 최대 3명까지 만들고(많을수록 운영자가 만들 이미지가 늘어난다),
씬마다 `cast` 로 누가 나오는지 적어 두어 어떤 이미지를 넣어야 하는지 화면에 보여 준다.
목록에 없는 사람은 뒷모습·실루엣·먼 군중으로만 나온다.
그래서 외모는 각 인물의 `image_prompt` 에서만 정하고, **씬 프롬프트에는 외모를 한 글자도
쓰지 않는다** — 참조 이미지와 글이 싸우면 이긴 쪽이 컷마다 달라져 옷이 계속 바뀐다.
`strip_look_words()` 가 씬 프롬프트에 외모 낱말이 새어 들어갔는지 검사해 경고한다.
(`verdict-theater/CLAUDE.md` 의 "루미나 3대 금지" 중 ①을 이식)

**인물은 말하지 않는다.** 나레이터가 들려주는 이야기라 인물이 입을 움직이면 누가 말하는지
헷갈리고, 영상 AI가 지어낸 영어 입모양은 한국어 나레이션과도 어긋난다. LLM 이 매번 쓰기를
기대하지 않고 `SILENCE_LOCK` 한 문장을 **모든 씬 프롬프트에 예외 없이 붙인다**.
발화 동작(shouts·sings 등)이 씬 내용에 섞이면 `talk_words()` 가 경고한다.

**씬 전환은 나레이션 여백 안에서 일어난다.** 각 씬 영상을 제 길이보다 전환 시간만큼 길게
만들어 두고, `xfade` 가 그 여분을 정확히 먹는다. 이 계산이 틀어지면 뒤로 갈수록 말과 그림이
밀리므로, k번째 전환은 앞선 씬 길이의 합에서 시작하고 마지막에 남는 한 번분만 잘라낸다.
전환 효과는 순서대로 돌려 써서 같은 효과가 반복되지 않게 한다.

**업로드와 재생은 워커가 중계한다.** 브라우저에서 깃허브 업로드 서버로 바로 쏘면
CORS 에 막히고(실제로 "연결이 끊겼습니다" 로 나타났다), 릴리스 주소는 `attachment` 로
내려와 사파리가 인라인 재생을 거부한다(검은 화면). 워커가 둘 다 풀어 준다.

## 알려진 제약

| 항목 | 내용 |
|---|---|
| 워크플로 위치 | GitHub 규칙상 `workflow_dispatch`는 **기본 브랜치(main)에 있는 워크플로만** 실행된다. |
| Gemini TTS 호출 수 | 자막 한 줄이 한 번의 호출이다. 8컷이면 20~30번 부른다. 무료 등급의 분당·일일 한도에 걸리면 자동으로 쉬었다 다시 시도하지만, 일일 한도를 넘기면 다음 날까지 기다려야 한다. `SUB_MAX_CHARS` 를 키우면 호출이 줄고 대신 줄이 길어진다. |
| Edge-TTS 차단 | 예비 엔진(`engine=edge`). 일부 데이터센터 IP에서 마이크로소프트가 403을 낼 수 있다. |
| 인물 일관성 | 기준 이미지를 영상 툴의 **참조 이미지** 칸에 매번 넣어야 효과가 있다. 안 넣으면 컷마다 인물이 달라진다. 한 씬에 두 명이 나오면 두 장을 같이 넣는다(툴이 지원해야 한다). |
| 업로드 용량 | 무료 Cloudflare 는 한 번에 100MB 까지 받는다. |
