# 점프리시 (Jumplish) — 보완 기획서 v2 (PRD)

> 원 기획서(v1)의 방향을 계승하고, 4가지 미확정 사항(시험 체계·콘텐츠 제작·인프라·MVP 순서)을
> 확정해 비어 있던 설계를 채운 문서입니다. 이 문서가 제품의 **단일 기준(master)** 이며,
> 세부 설계는 [docs/ERD.md](docs/ERD.md) · [docs/engine.md](docs/engine.md) ·
> [docs/content-pipeline.md](docs/content-pipeline.md)로 나눠 관리합니다.

---

## 1. 개요와 목표

| 항목 | 내용 |
|---|---|
| 프로젝트명(브랜드) | **점프리시 (Jumplish)** — 앱 표기 "점프리시 — 영어 레벨 점프" (저장소 코드네임 `junior-toeic-master` 유지, 상표 정식 검토는 8절) |
| 서비스 목표 | '산타토익'의 개인 맞춤형 약점 분석 + 'abceed'의 풍부한 콘텐츠 장점을 결합한 초·중등(주니어) 영어 학습 플랫폼 |
| 타깃 사용자 | **초3~중3** 학생 — 학년 그룹 2개: **주니어(초3~4)** / **기본(초5~중3)** + 영어학원 강사·원장 |
| 비즈니스 목표 | B2B(영어학원) 제휴로 초기 1만 학생 확보, 학생 1인당 월 5,000원 구독 → **MRR 5,000만 원** |
| 핵심 개발 원칙 | **운영 중 외부 LLM·실시간 TTS API 호출 0회** (비용 0원 수렴). 자체 규칙 기반 알고리즘 + 정적 파일 서빙 |

**왜 주니어 시장인가**: 성인 토익은 산타토익 등으로 포화 상태지만, 초·중등 대상
"진단 → 맞춤 문제 → 자동 오답 관리"를 갖춘 서비스는 공백에 가깝다. 학원은 반별 수준 편차
관리와 학부모 리포트가 상시 고민이므로, 자동화된 개인 맞춤 학습 + 반 대시보드는 B2B 영업
소구점이 명확하다.

## 2. 확정 결정사항

| 결정 | 확정 내용 | 근거 |
|---|---|---|
| 시험 기준 | **TOEIC Bridge** (ETS의 초·중급용 공식 토익) | 초·중등 수준 적합, '주니어 토익' 학원 커리큘럼과 일치 |
| 콘텐츠 제작 | **AI 배치 생성 + 사람 검수** — 개발 단계 1회성 제작, 운영 중 생성 0회 | 운영비 0원 원칙 유지, 상세는 [content-pipeline.md](docs/content-pipeline.md) |
| 인프라 | **Cloudflare 풀스택** (Workers + D1 + R2 + 정적 assets) | 1만 학생 규모까지 월 $5 수준, 기존 배포 경험(book-carousel)과 동일 생태계 |
| MVP 순서 | **학생 학습 루프 먼저** (M2), B2B 대시보드는 M4 | 제품의 심장인 추천 엔진을 실데이터로 먼저 검증 |
| 브랜드명 | **점프리시 (Jumplish)** (2026-08-08 확정) | 1차 검색 청정 — KIPRIS 정식 검토는 M4 전 (8절) |
| 타깃 학년 | **초3~중3** — 주니어(초3~4)·기본(초5~중3) 2그룹 | 주니어 프리셋: 진단 16문항·세트 12문항·0.9배속 듣기 |

### TOEIC Bridge 시험 구조 (검증 완료)

영역별 15~50점, **총점 30~100점**. 전 문항 4지선다.

| 영역 | 파트 | 이름 | 문항 수 | 코드 |
|---|---|---|---|---|
| Listening (50문항 · 약 25분) | Part 1 | Four Pictures (사진 고르기) | 6 | `L1` |
| | Part 2 | Question-Response (질의응답) | 20 | `L2` |
| | Part 3 | Conversations (짧은 대화) | 10 (대화 5개×2문항) | `L3` |
| | Part 4 | Talks (짧은 담화) | 14 (담화 7개×2문항) | `L4` |
| Reading (50문항 · 35분) | Part 1 | Sentence Completion (문장 완성) | 15 | `R1` |
| | Part 2 | Text Completion (지문 완성) | 15 (지문 5개×3문항) | `R2` |
| | Part 3 | Reading Comprehension (독해) | 20 | `R3` |

- 출처: [ETS 공식 소개](https://www.ets.org/toeic/about/bridge.html) ·
  [ETS 연구 메모 RM-21-01](https://files.eric.ed.gov/fulltext/ED617522.pdf) ·
  [Global-Exam 구조 안내](https://global-exam.com/blog/en/toeic-bridge-what-is-the-test-structure/)
- 듣기 성우는 실전처럼 **미국·영국·호주 발음**을 섞어 사전 녹음(배치 TTS)한다.

## 3. 사용자와 시나리오 (4역할)

| 역할 | 핵심 여정 |
|---|---|
| **학생** | 학원이 나눠준 로그인ID+PIN으로 접속 → 최초 1회 진단(기본 24문항·주니어 16문항) → 매일 "오늘의 학습" 완료 → 틀린 문제는 자동으로 오답노트에 쌓이고 예정일에 다시 출제 → XP·레벨·스트릭으로 동기 유지 |
| **강사** | 반 생성 → 학생 CSV 일괄 등록(ID·PIN 자동 발급) → 시스템 추천 세트를 검토해 과제로 발행 → 반 리포트에서 진도·정답률·취약 파트·미완료 학생 확인 |
| **학원 관리자(원장)** | 학원 계정 개설(가입 코드 발급) → 강사 계정 관리 → 학원 전체 이용 현황·정산(M5) 확인 |
| **운영자(우리)** | 문항 저작·검수·배포(콘텐츠 파이프라인), 지표 모니터링, 학원 온보딩 지원 |

### 화면 목록

- **학생**: 로그인 / 홈(오늘의 학습·스트릭·레벨) / 진단 테스트 / 문제 풀이(LC·RC) / 문항 결과·해설 / 세트 완료 요약 / 오답노트 / 내 리포트 / 뱃지·프로필
- **강사**: 반 목록 / 학생 관리(CSV 등록·PIN 재발급) / 과제 만들기(추천 세트 미리보기) / 과제 현황 / 반 리포트
- 모바일 세로 화면 우선(학생은 대부분 폰으로 풀이), PC 병행 지원.

## 4. 학생 기능 명세

### 4-1. 초기 진단 테스트

- 학년 그룹별 길이: **기본(초5~중3) 24문항 = 12+12 (약 15분)**, **주니어(초3~4) 16문항 = 8+8
  (약 10분)** — 저학년 집중력을 고려해 더 짧게. 중간에 격려 화면 1회, 중단 시 이어하기 지원.
- 기본 그룹 1단계: 전 파트 배분(L1 1·L2 2·L3 2·L4 2·R1 2·R2 1·R3 2), 중간 난이도(라벨 3) 중심.
  주니어 그룹은 **라벨 2에서 시작**하며 파트 배분표는 [engine.md](docs/engine.md) 참조.
- 2단계: 같은 파트 배분, 난이도는 1단계 **섹션(LC/RC) 정답률**에 따라 상·중·하 조정.
- 주니어 그룹은 문항 표본이 작으므로 파트별 등급에 "참고용" 문구를 병기한다.
- 결과: 파트별 정답률 대역을 초기 실력치(레이팅)로 직접 매핑(수식은 [engine.md](docs/engine.md)).
  리포트는 **파트별 5등급**만 표시 — 예측 점수는 표시하지 않는다(보정 데이터 없는 가짜 정밀도 방지).
- 진단 중에는 문항별 해설을 보여주지 않고(흐름 유지), 종료 후 결과 화면에서 확인.

### 4-2. 오늘의 맞춤 학습

- 매일 1세트 자동 생성. **기본 20문항 = 복습 6 + 약점 8 + 신규 4 + 강점 유지 2**
  (**주니어(초3~4) 그룹 기본 12문항 = 4/5/2/1**, 세트 크기는 반 설정으로 강사가 조정 — M4).
- 약점 문항은 "약간 어렵게 느껴지는" 예상 정답률 55~75% 구간에서 뽑고, 최근 14일 내 본 문항은
  제외(복습 슬롯 예외). LC 대화·담화는 지문 묶음 통째로 출제. LC·RC 각각 최소 30% 보장.
- 생성 규칙 전체와 부족분 채우기 순서는 [engine.md](docs/engine.md) 참조.

### 4-3. 문제 풀이 UX

- 한 문항 풀 때마다 **즉시 채점 + 해설** 표시 (실전 모의 모드는 추후).
- LC: 음원 자동 재생 + 다시 듣기 1회 허용(학습 모드), R2 정적 파일을 클라이언트가 직접 fetch.
- 주니어 그룹은 듣기 플레이어에 **천천히 듣기(0.9배속)** 옵션 제공 — 음원은 한 벌만 제작하고
  재생 속도로 대응한다(추가 제작·저장 없음, 운영비 0원 원칙 유지).
- **정답·해설은 서버에만 있다**: 문항 조회 API 응답에는 보기까지만 포함, 채점 API가 정답 대조
  후 해설을 반환. 개발자도구를 열어도 정답이 보이지 않는다.
- 풀이 시간(time_ms)을 기록 — 2초 미만 답변은 '찍기'로 간주해 보상·실력 반영을 낮춘다
  (아동의 연타 남용 방지, [engine.md](docs/engine.md)).

### 4-4. 오답노트 & 반복 복습 (SRS)

- 틀린 문항은 자동으로 복습 큐에 등록되고 **라이트너 박스**(1→4)를 따라 +1일/+3일/+7일/+14일
  뒤 다시 출제된다. 복습에서 또 틀리면 박스 1로 리셋, 박스 4에서 맞히면 "졸업".
- 오답노트 화면: 틀린 문항 목록(파트·태그 필터), 오늘 복습 예정 수, 졸업한 문항 수.
- 어떤 모드에서든(일일 세트·과제 포함) 해당 문항을 맞히면 박스가 진급한다.

### 4-5. 게이미피케이션

- **XP**: 정답 10~18(난이도 비례), 오답 2, 찍기 1, **일일 세트 완주 보너스 +30**
  (완주가 체리피킹보다 이득이 되도록).
- **레벨**: 누적 XP 기준 곡선(레벨 L 도달 = 100×L^1.5 XP). 하루 성실 학습 시 약 5일에 Lv5,
  2주에 Lv10 — 초반 성취감을 빠르게.
- **스트릭**: "일일 세트 완료" 또는 "아무 모드나 10문항 이상"이면 그날 출석 인정 (KST 자정 기준).
- **뱃지 카탈로그 초안 (8종)** — 판정 로직은 코드에 두고, DB에는 표시 정보만 저장:

| 코드 | 이름 | 조건 |
|---|---|---|
| `first-steps` | 첫걸음 | 진단 테스트 완료 |
| `streak-7` | 7일의 약속 | 스트릭 7일 |
| `streak-30` | 한 달의 기적 | 스트릭 30일 |
| `perfect-set` | 퍼펙트! | 일일 세트 전 문항 정답 |
| `review-master` | 복습왕 | 오답 20문항 졸업 |
| `hundred-club` | 100문제 클럽 | 누적 100문항 풀이 |
| `lc-explorer` | 듣기 탐험가 | LC 4개 파트 각 10문항 이상 |
| `rc-explorer` | 읽기 탐험가 | RC 3개 파트 각 10문항 이상 |

- 아이콘은 OS 이모지가 아닌 **커스텀 일러스트/벡터**로 제작(저장소 공통 원칙).

## 5. B2B 기능 명세 (M4)

### 5-1. 학원·반·계정 구조

- 학원 생성 시 **가입 코드**(예: `HAPPY01`) 발급. 학생 로그인ID는 `{가입코드}-{순번}`
  형식(예: `HAPPY01-0007`)으로 서버가 자동 발급 — 전역 유일, 학생이 이메일을 만들 필요 없음.
- 자격증명은 **로그인ID + 6자리 PIN**. PIN은 해시로만 저장, 강사가 재발급 가능.

### 5-2. 학생 CSV 일괄 등록

- 입력 CSV (UTF-8, 헤더 필수): `이름,학년,반` — **개인정보 최소 수집**(연락처·생년월일 없음).

```csv
이름,학년,반
김하늘,초6,월수금A
이준서,중1,화목B
```

- 처리: 반 이름 자동 매칭(미존재 시 생성 확인) → 계정 생성 → 로그인ID·초기 PIN 자동 발급.
- 출력: `이름,반,로그인ID,초기PIN` CSV 다운로드 (강사가 인쇄해 배부).
- 엑셀(.xlsx) 파일은 "CSV로 저장" 안내로 시작(MVP), xlsx 직접 파싱은 M4에서 검토.

### 5-3. 과제 (Assignment)

- 유형 3종: ① **추천 세트**(반 평균 약점 기반 자동 구성) ② **파트 지정**(예: R1 15문항)
  ③ **직접 선택**(문항 검색·선택).
- 흐름: 강사가 세트 **미리보기 → 확정 발행**. 발행 시 문항 목록을 스냅샷으로 고정해
  학생 간 동일 세트 보장. 마감일 설정 가능.
- 학생별 이행 현황(미시작/진행/완료·정답률)을 실시간 표시.

### 5-4. 반 리포트

- 지표: 반 평균 정답률 추이(주간), 파트·태그별 취약 순위, 학생별 학습일수·완료율,
  미완료 학생 목록(독려 대상).
- 모든 리포트는 **집계 테이블만 조회**(원본 풀이 로그를 스캔하지 않음 — 7절 성능 원칙).

## 6. API 초안

인증: 로그인ID+PIN → Worker가 **HMAC 서명 토큰**(만료 24h) 발급. 토큰 테이블 없음
(요청당 DB 조회 0회로 검증). 역할(role) 가드는 Hono 미들웨어.

### 학생 API

| 메서드·경로 | 기능 | 비고 |
|---|---|---|
| `POST /api/auth/login` | 로그인ID+PIN → 토큰 | |
| `GET /api/me` | 프로필 + XP·레벨·스트릭 | |
| `POST /api/diagnostic/start` | 진단 시작, 1단계 12문항 발급 | 문항에 정답 없음 |
| `POST /api/diagnostic/submit` | 단계 답안 제출 → 2단계 발급 또는 최종 리포트 | 진단은 일괄 채점 |
| `GET /api/daily` | 오늘의 세트 조회(없으면 생성) | 세트 구성 내역(slots) 포함 |
| `POST /api/answers` | 한 문항 채점 → 정오·해설·XP·복습 예약 반환 | 스킬·SRS·XP·일별 집계 원자 처리 |
| `POST /api/sessions/:id/finish` | 세트 종료 → 요약·완주 보너스·스트릭·뱃지 | |
| `GET /api/review` | 오답노트 목록·오늘 복습 예정 | |
| `GET /api/report` | 파트별 등급·태그별 숙련도·최근 추이 | 집계 테이블 조회 |

### 강사·관리자 API (M4)

| 메서드·경로 | 기능 |
|---|---|
| `POST /api/admin/classes` | 반 생성·수정 |

## 8. 법률·정책 리스크

1. **상표**: "TOEIC"·"TOEIC Bridge"는 ETS 등록상표. 서비스 브랜드명은 **"점프리시 (Jumplish)"로
   확정**(2026-08-08 — 1차 검색상 동명 앱·서비스 없음, 유사명은 해외 앱 Jumpspeak 정도).
   **M4 학원 영업 전** KIPRIS 정식 상표 검색·출원 검토와 도메인(jumplish.kr 등) 확보를 마친다.
   "TOEIC Bridge 대비"는 상표적 사용이 아닌 **설명 문구로만** 쓴다. 저장소 폴더·코드네임
   (`junior-toeic-master`)은 내부용으로 유지한다.
2. **저작권**: 실제 기출문제·공식 교재의 복제·전재 금지. 문항은 시험의 *형식·유형만* 참고해
   **100% 자체 창작**하며, 검수 체크리스트에 "기출 유사성 자가점검" 항목을 포함한다
   ([content-pipeline.md](docs/content-pipeline.md)).
3. **개인정보(PIPA)**: 대상이 대부분 만 14세 미만이므로 **수집 자체를 최소화**한다 —
   학생 테이블에 이메일·전화 **컬럼이 아예 없다**. 계정은 학원이 발급(이름·학년·반만),
   법정대리인 동의는 학원의 수강 계약·서면 동의로 처리하고 우리는 처리위탁 관계를 계약서에
   명시한다(학원 온보딩 키트에 동의서 양식 포함 — M4).
4. **B2C 직접 가입은 후순위**: 만 14세 미만 본인 가입은 법정대리인 동의 시스템이 필요하므로
   MVP에서는 학원 경유 가입만 지원한다.

## 11. 로드맵 M0~M5

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| **M0 (완료)** | 기획 보완 문서 패키지 (본 문서 + ERD·엔진·콘텐츠 설계) | 문서 push·가드 통과 |
| **M1** | 스캐폴드: Workers(Hono)+D1 마이그레이션+웹 골격, 콘텐츠 도구(임포트·배치 TTS), **시드 120문항+음원**, 배포 워크플로 | 로컬에서 문항 열람 + 음원 재생 |
| **M2** | 학생 코어 루프: 로그인, 진단 24문항, 오늘의 학습, 채점·실력 갱신, 오답노트 SRS | 진단→일일학습→오답복습 1주 사이클 동작 |
| **M3** | 게이미피케이션(XP·레벨·스트릭·뱃지) + 학생 리포트 + 모바일 PWA 폴리시 | **지인 자녀 테스터(초3~중3)** 실사용 검증 |
| **M4** | B2B: 학원·반 관리, CSV 일괄 등록, 과제 발행·현황, 반 대시보드, 온보딩 키트(동의서 포함) + **파일럿 학원 확보(테스터 검증 결과로 영업)** | 파일럿 학원 1곳 온보딩 |
| **M5** | 결제(좌석제 인보이스→PG), 운영 어드민(문항 관리·지표), 베타 확대 | 유료 전환 1건 |

각 단계는 저장소 규칙대로 `junior-toeic-master/` 단독 커밋으로 진행하며(`.github/` 워크플로만
별도 커밋), 매 단계 완료 시 로컬 서버 기동·모바일 세로 화면 검증을 거친다.
