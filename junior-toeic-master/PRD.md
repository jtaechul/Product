# 점프리시 (Jumplish) — 보완 기획서 v2 (PRD)

> 원 기획서(v1)의 방향을 계승하고, 4가지 미확정 사항(시험 체계·콘텐츠 제작·인프라·MVP 순서)을
> 확정해 비어 있던 설계를 채운 문서입니다. 이 문서가 제품의 **단일 기준(master)** 이며,
> 세부 설계는 [docs/ERD.md](docs/ERD.md) · [docs/engine.md](docs/engine.md) ·
> [docs/content-pipeline.md](docs/content-pipeline.md)로 나눠 관리합니다.

## 1. 개요와 목표

| 항목 | 내용 |
|---|---|
| 프로젝트명(브랜드) | **점프리시 (Jumplish)** — 앱 표기 "점프리시 — 영어 레벨 점프" (저장소 코드네임 `junior-toeic-master` 유지, 상표 정식 검토는 8절) |
| 서비스 목표 | '산타토익'의 개인 맞춤형 약점 분석 + 'abceed'의 풍부한 콘텐츠 장점을 결합한 초·중등(주니어) 영어 학습 플랫폼 |
| 사용하는 사람 | **초3~중3** 학생 — 학년 그룹 2개: **주니어(초3~4)** / **기본(초5~중3)** |
| **돈을 내는 사람** | **학부모** (2026-08-11 확정 — B2B 학원 좌석제에서 전환) |
| 비즈니스 목표 | **무료 진단으로 유입 → 학부모 월 구독 8,900원.** 단계 목표: 유료 100명(MRR 89만) → 1,000명(890만) → 5,000명(4,450만) |
| 핵심 개발 원칙 | **운영 중 외부 LLM·실시간 TTS API 호출 0회** (비용 0원 수렴). 자체 규칙 기반 알고리즘 + 정적 파일 서빙 |

**왜 주니어 시장인가**: 성인 토익은 산타토익 등으로 포화 상태지만, 초·중등 대상
"진단 → 맞춤 문제 → 자동 오답 관리"를 갖춘 서비스는 공백에 가깝다.

**왜 학부모에게 파는가**: 아이는 결제력이 없지만 **결제자는 처음부터 학부모**다. 학원비·학습지에
이미 지출하는 가정에서 월 8,900원은 "끊을지 고민하는 돈"이 아니라 "일단 넣어두는 돈"이다.
학원을 대체하겠다고 하면 비싸 보이므로, **"학원 다니는 아이가 집에서 10분 더"** 로 포지셔닝한다.

**우리가 파는 것은 문제집이 아니라 "우리 아이가 정확히 어디가 약한지"** 다. 학원 강사도 학습지도
감으로만 말해 주는 것을, 이 앱은 진단과 매일의 답안에서 데이터로 뽑아 보여준다. 학부모가 지갑을
여는 지점이 여기이고, 진단·실력 지도·학부모 화면은 M2~M3에서 이미 만들어져 있다.

**운영비 0원 원칙이 곧 사업 모델의 무기다**: 사용자당 한계비용이 사실상 0이라 **무료 사용자를
아무리 많이 안고 가도 손해가 없다.** 매 세션 LLM·TTS를 호출하는 경쟁 앱은 무료 구간을 이렇게
넓게 열 수 없다. "하루 1세트는 계속 무료"를 지킬 수 있는 이유다.

## 4. 학생 기능 명세

### 4-1. 초기 진단 테스트

- 학년 그룹별 길이: **기본(초5~중3) 24문항 = 12+12 (약 15분)**, **주니어(초3~4) 16문항 = 8+8
  (약 10분)** — 저학년 집중력을 고려해 더 짧게. 중간에 격려 화면 1회, 중단 시 이어하기 지원.
- 기본 그룹 1단계: 전 파트 배분(L1 1·L2 2·L3 2·L4 2·R1 2·R2 1·R3 2), 중간 난이도(라벨 3) 중심.
  주니어 그룹은 **라벨 2에서 시작**하며 파트 배분표는 [engine.md](docs/engine.md) 참조.
- 2단계: 같은 파트 배분, 난이도는 1단계 **섹션(LC/RC) 정답률**에 따라 상·중·하 조정.
- 주니어 그룹은 문항 표본이 작으므로 파트별 등급에 "참고용" 문구를 병기한다.
- 결과: 파트별 정답률 대역을 초기 실력치(레이팅)로 직접 매핑(수식은 [engine.md](docs/engine.md)).
  리포트는 **파트별 5등급**만 표시 — 예측 점수는 표시하지 않는다(보정 데이터 없는 가짜 정밀도 방지).
- 진단 중에는 문항별 해설을 보여주지 않고(흐름 유지), 종료 후 결과 화면에서 확인.

### 4-2. 오늘의 맞춤 학습

- 매일 1세트 자동 생성. **기본 20문항 = 복습 6 + 약점 8 + 신규 4 + 강점 유지 2**
  (**주니어(초3~4) 그룹 기본 12문항 = 4/5/2/1**). 학부모가 만든 아이 계정은 반이 없으므로
  기본값 12문항으로 시작한다 — 학년에 따른 세트 크기 선택은 M4 이후 학부모 화면에서 검토.
- 약점 문항은 "약간 어렵게 느껴지는" 예상 정답률 55~75% 구간에서 뽑고, 최근 14일 내 본 문항은
  제외(복습 슬롯 예외). LC 대화·담화는 지문 묶음 통째로 출제. LC·RC 각각 최소 30% 보장.
- 생성 규칙 전체와 부족분 채우기 순서는 [engine.md](docs/engine.md) 참조.

### 4-3. 문제 풀이 UX

- 한 문항 풀 때마다 **즉시 채점 + 해설** 표시 (실전 모의 모드는 추후).
- LC: 음원 자동 재생 + 다시 듣기 1회 허용(학습 모드), R2 정적 파일을 클라이언트가 직접 fetch.
- 주니어 그룹은 듣기 플레이어에 **천천히 듣기(0.9배속)** 옵션 제공 — 음원은 한 벌만 제작하고
  재생 속도로 대응한다(추가 제작·저장 없음, 운영비 0원 원칙 유지).
- **정답·해설은 서버에만 있다**: 문항 조회 API 응답에는 보기까지만 포함, 채점 API가 정답 대조
  후 해설을 반환. 개발자도구를 열어도 정답이 보이지 않는다.
- 풀이 시간(time_ms)을 기록 — 2초 미만 답변은 '찍기'로 간주해 보상·실력 반영을 낮춘다
  (아동의 연타 남용 방지, [engine.md](docs/engine.md)).

### 4-4. 오답노트 & 반복 복습 (SRS)

- 틀린 문항은 자동으로 복습 큐에 등록되고 **라이트너 박스**(1→4)를 따라 +1일/+3일/+7일/+14일
  뒤 다시 출제된다. 복습에서 또 틀리면 박스 1로 리셋, 박스 4에서 맞히면 "졸업".
- 오답노트 화면: 틀린 문항 목록(파트·태그 필터), 오늘 복습 예정 수, 졸업한 문항 수.
- 어떤 모드에서든(일일 세트·과제 포함) 해당 문항을 맞히면 박스가 진급한다.

### 4-5. 게이미피케이션

- **XP**: 정답 10~18(난이도 비례), 오답 2, 찍기 1, **일일 세트 완주 보너스 +30**
  (완주가 체리피킹보다 이득이 되도록).
- **레벨**: 누적 XP 기준 곡선(레벨 L 도달 = 100×L^1.5 XP). 하루 성실 학습 시 약 5일에 Lv5,
  2주에 Lv10 — 초반 성취감을 빠르게.
- **스트릭**: "일일 세트 완료" 또는 "아무 모드나 10문항 이상"이면 그날 출석 인정 (KST 자정 기준).
- **뱃지 카탈로그 초안 (8종)** — 판정 로직은 코드에 두고, DB에는 표시 정보만 저장:

| 코드 | 이름 | 조건 |
|---|---|---|
| `first-steps` | 첫걸음 | 진단 테스트 완료 |
| `streak-7` | 7일의 약속 | 스트릭 7일 |
| `streak-30` | 한 달의 기적 | 스트릭 30일 |
| `perfect-set` | 퍼펙트! | 일일 세트 전 문항 정답 |
| `review-master` | 복습왕 | 오답 20문항 졸업 |
| `hundred-club` | 100문제 클럽 | 누적 100문항 풀이 |
| `lc-explorer` | 듣기 탐험가 | LC 4개 파트 각 10문항 이상 |
| `rc-explorer` | 읽기 탐험가 | RC 3개 파트 각 10문항 이상 |

- 아이콘은 OS 이모지가 아닌 **커스텀 일러스트/벡터**로 제작(저장소 공통 원칙).

## 5. 계정·구독 명세 (M4)

### 5-0. 가입 순서를 뒤집는다 (B2C 전환의 핵심)

기존 B2B 구조는 **학원이 아이 계정을 발급**했다. 학부모 직접 구독으로 가면 순서가 뒤집힌다.

```
[전] 학원 가입 → 학원이 아이 계정 발급 → 학부모는 조회만
[후] 학부모 가입(결제자) → 학부모가 아이 계정 생성 → 아이가 로그인해서 학습
```

이 한 번의 뒤집기로 두 가지가 동시에 풀린다.

1. **법정대리인 동의**(만 14세 미만 필수)가 가입 절차 안에서 자연히 처리된다.
   학원 서면 동의서에 기대던 것을 우리가 직접 받는다.
2. **결제자 연락처를 어디에 둘지**가 정리된다 — 이메일·전화는 **학부모 레코드에만** 두고,
   **아이 테이블은 지금처럼 개인정보 컬럼 0개를 그대로 유지**한다(8절 3항 원칙 유지).

| | 학부모 계정 | 아이 계정 |
|---|---|---|
| 로그인 | 이메일 + 비밀번호(8자 이상) | 로그인ID + 6자리 PIN (기존 그대로) |
| 저장하는 개인정보 | 이메일, (선택)휴대폰 — 결제·알림용 | **없음** (표시 이름·학년만) |
| 하는 일 | 결제, 리포트 열람, 아이 추가·PIN 재발급 | 학습만 |

### 5-1. 아이 로그인ID 발급 규칙

- **`JP-XXXXXX`** (전역 유일 랜덤 6자리). 학부모가 화면에서 아이를 추가하면 즉시 발급한다.
  헷갈리는 글자(0·O·1·I·5·S)는 빼고 만든다 — 아이가 종이에 적힌 걸 보고 직접 입력하기 때문이다.
- 자격증명은 **로그인ID + 6자리 PIN**. PIN은 해시로만 저장하고 학부모가 재발급한다.
- 학원이 발급하던 `{가입코드}-{순번}` 경로와 학부모용 PIN 로그인은 **없앴다**(2026-08-11).
  학원 영업을 하지 않기로 하면서 그 화면이 사라졌고, 들어갈 문이 없는 열쇠를 남겨둘 이유가 없다.
  (academies·classes 표와 관리자 화면은 남아 있다 — 테스터 계정을 만들 때 쓴다.)

### 5-2. 무료·유료 경계

**아이의 학습을 막지 않는다.** 아이가 재미없어 떠나면 학부모는 곧바로 해지한다.
그래서 페이월은 **분량과 학부모용 리포트**에만 건다.

| 기능 | 무료 | 유료 (월 8,900원) |
|---|---|---|
| 진단 + 결과 요약 | O | O |
| 하루 학습 | **1세트 (기간 제한 없음)** | 무제한 |
| 오답 복습(리매치) | 하루 1회 | 무제한 |
| 등반 지도·봉인 앨범 | O | O |
| **주간 학부모 리포트(알림)** | X | **O** |
| 상세 실력 지도·성장 그래프 | X | O |
| 아이 계정 수 | 1명 | 최대 3명 |

### 5-2. 학생 CSV 일괄 등록

- 입력 CSV (UTF-8, 헤더 필수): `이름,학년,반` — **개인정보 최소 수집**(연락처·생년월일 없음).

```csv
이름,학년,반
김하늘,초6,월수금A
이준서,중1,화목B
```

- 처리: 반 이름 자동 매칭(미존재 시 생성 확인) → 계정 생성 → 로그인ID·초기 PIN 자동 발급.
- 출력: `이름,반,로그인ID,초기PIN` CSV 다운로드 (강사가 인쇄해 배부).
- 엑셀(.xlsx) 파일은 "CSV로 저장" 안내로 시작(MVP), xlsx 직접 파싱은 M4에서 검토.

### 5-3. 과제 (Assignment)

- 유형 3종: ① **추천 세트**(반 평균 약점 기반 자동 구성) ② **파트 지정**(예: R1 15문항)
  ③ **직접 선택**(문항 검색·선택).
- 흐름: 강사가 세트 **미리보기 → 확정 발행**. 발행 시 문항 목록을 스냅샷으로 고정해
  학생 간 동일 세트 보장. 마감일 설정 가능.
- 학생별 이행 현황(미시작/진행/완료·정답률)을 실시간 표시.

### 5-4. 반 리포트

- 지표: 반 평균 정답률 추이(주간), 파트·태그별 취약 순위, 학생별 학습일수·완료율,
  미완료 학생 목록(독려 대상).
- 모든 리포트는 **집계 테이블만 조회**(원본 풀이 로그를 스캔하지 않음 — 7절 성능 원칙).

## 8. 법률·정책 리스크

1. **상표**: "TOEIC"·"TOEIC Bridge"는 ETS 등록상표. 서비스 브랜드명은 **"점프리시 (Jumplish)"로
   확정**(2026-08-08 — 1차 검색상 동명 앱·서비스 없음, 유사명은 해외 앱 Jumpspeak 정도).
   **M4 학원 영업 전** KIPRIS 정식 상표 검색·출원 검토와 도메인(jumplish.kr 등) 확보를 마친다.
   "TOEIC Bridge 대비"는 상표적 사용이 아닌 **설명 문구로만** 쓴다. 저장소 폴더·코드네임
   (`junior-toeic-master`)은 내부용으로 유지한다.
2. **저작권**: 실제 기출문제·공식 교재의 복제·전재 금지. 문항은 시험의 *형식·유형만* 참고해
   **100% 자체 창작**하며, 검수 체크리스트에 "기출 유사성 자가점검" 항목을 포함한다
   ([content-pipeline.md](docs/content-pipeline.md)).
3. **개인정보(PIPA)**: 대상이 대부분 만 14세 미만이므로 **수집 자체를 최소화**한다 —
   학생 테이블에 이메일·전화 **컬럼이 아예 없다**. 이 원칙은 B2C 전환 후에도 그대로다:
   결제·알림에 필요한 연락처는 **학부모 레코드에만** 두고 아이 레코드는 건드리지 않는다(5-0).
4. **법정대리인 동의는 이제 우리가 직접 받는다** (2026-08-11, B2C 전환에 따라 변경).
   학부모가 먼저 가입하고 아이 계정을 만드는 순서라 동의가 가입 절차 안에서 처리된다.
   동의 시각·동의 항목·동의한 학부모 계정을 기록으로 남긴다.
5. **아동 대상 서비스의 수익화 금지선** (2026-08-11 확정):
   - **광고를 붙이지 않는다.** 만 14세 미만 대상 행동 타깃 광고는 법적 위험이 크고,
     앱스토어 아동 카테고리 정책과도 충돌한다. 수익 규모도 구독에 비해 미미하다.
   - **아이가 결제하는 구조를 만들지 않는다.** 게임 아이템식 인앱결제는 미성년자 결제
     취소 분쟁으로 직결된다. 결제 화면은 **학부모 계정에서만** 열린다.
   - **학습 자체를 페이월로 막지 않는다.** 무료로도 매일 쓸 수 있어야 한다(5-2).

## 9. 수익화 방향 (2026-08-11 전면 개정 — B2B 좌석제에서 B2C 학부모 구독으로)

### 9-1. 판매 구조

```
무료 진단 10분  →  "우리 아이 영어 약점 리포트"를 학부모가 눈으로 봄
                →  그 자리에서 "이 약점을 매일 10분씩 메워드립니다"
                →  월 8,900원 구독
```

전환이 가장 잘 일어나는 순간은 **학부모가 아이의 약점을 막 확인한 직후**다. 그래서 진단 결과
화면이 곧 결제 제안 화면이다. 진단·실력 지도·학부모 화면은 이미 만들어져 있으므로 새로 만들
것은 **결제와 무료·유료 경계**뿐이다.

### 9-2. 가격

| 항목 | 값 | 근거 |
|---|---|---|
| **기본 요금** | **월 8,900원** (2026-08-11 확정) | 학습지 1과목(월 4만 원대)의 1/4 수준. 학원 대체가 아니라 "집에서 10분 더"의 가격 |
| 형제 결합 | 검토 (2인 요금제) | 초등 자녀 2명 가정이 많다. 객단가를 올리면서 해지도 막는다 |
| 학기 선결제 | 검토 (3개월 할인) | 한국 학부모는 월 자동결제보다 "한 학기 한 번에"에 익숙하다. 현금흐름 + 이탈 방지 |

### 9-3. 마진 구조 (운영비 0원 원칙의 효과)

운영 중 외부 API 호출이 0회라 **사용자당 한계비용이 사실상 0**이다. 무료 사용자가 크게 늘어도
인프라 비용은 요청 수에 비례해 아주 완만하게만 오른다(7절 규모·비용 참조 — 추정치이므로
실사용 데이터로 재확인 필요). 결제 수수료를 빼면 구독료 대부분이 마진이다.

→ **경쟁 앱이 따라 하기 어려운 지점**: 매 세션 LLM·TTS를 호출하는 서비스는 무료 구간을
이만큼 넓게 열면 적자가 난다. "하루 1세트 계속 무료"는 우리만 지킬 수 있는 약속이다.

### 9-4. 학원 영업은 하지 않는다

학원 좌석제·학원 경유 가입·구독료 정산은 **모두 접었다**(2026-08-11). 고객은 학부모 한 쪽이다.
제품 화면 어디에도 학원을 거쳐 들어오는 길을 두지 않는다 — 학부모가 "학원에서 아이디를
받으셨나요?" 같은 문구를 보면 우리가 누구에게 파는 서비스인지 헷갈린다.

academies·classes 표와 관리자 화면은 남아 있지만, 이제 **테스터 계정을 만드는 내부 도구**일 뿐이다.

### 9-5. 부가 수익 (우선순위 낮음, 원가 0)

- **오답 프린트(PDF)** — 이번 주 틀린 문항만 모은 A4 한 장. 만드는 비용 0, 학부모 만족도 높음.
- **리퍼럴** — 친구·형제 초대 시 양쪽에 무료 1개월.

| **M4** | **B2C 전환**: 학부모 가입(이메일+비밀번호)·법정대리인 동의, 학부모가 아이 계정 생성, 무료/유료 경계(하루 1세트), 주간 학부모 리포트 | 학부모가 스스로 가입해 아이를 등록하고 학습까지 도달 |

| **M6** | 획득: 무료 진단 랜딩 페이지, 진단 결과 → 결제 제안 동선, 운영 어드민(문항 관리·지표) | 진단 완료 → 구독 전환율 측정 시작 |

> **M4 이전 로드맵과 달라진 점** (2026-08-11): 원래 M4는 학원 대시보드, M5는 학원 좌석제
> 결제였다. 고객을 학부모로 바꾸면서 **학원 영업은 접고**, 새 M4·M5를 학부모 가입·동의·
> 구독 결제로 대체한다.

각 단계는 저장소 규칙대로 `junior-toeic-master/` 단독 커밋으로 진행하며(`.github/` 워크플로만
별도 커밋), 매 단계 완료 시 로컬 서버 기동·모바일 세로 화면 검증을 거친다.
