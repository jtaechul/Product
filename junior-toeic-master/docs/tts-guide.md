# 듣기 음원 만들기 가이드 (Google TTS · 1회성 작업)

> 이 작업은 **개발 단계에서 딱 한 번**만 하면 됩니다. 만들어진 MP3는 영구 보관되고,
> 서비스 운영 중에는 TTS를 다시 호출하지 않습니다(운영비 0원 원칙).
> 실제 스크립트 실행은 준비물만 갖춰지면 Claude Code가 대신 해드릴 수 있습니다 —
> **아래 1단계(API 키 발급)만 직접 해주시면 됩니다.**

## 1단계 — Google API 키 발급 (직접, 약 10분)

1. 브라우저에서 [Google Cloud 콘솔](https://console.cloud.google.com)을 열고 구글 계정으로 로그인하세요.
2. 처음이라면 "무료로 시작하기"를 누르고 안내를 따라 가입하세요.
   - 카드 등록을 요구하지만, **무료 한도(뉴럴 음성 월 100만 자) 안에서는 요금이 나가지 않습니다.**
   - 우리가 쓸 양은 시드 120문항 기준 **수만 자**라서 무료 한도의 5%도 안 됩니다.
3. 화면 위쪽 검색창에 `Text-to-Speech` 를 입력 → **"Cloud Text-to-Speech API"** 클릭 → 파란색 **"사용(Enable)"** 버튼 클릭.
4. 왼쪽 메뉴(줄 3개 아이콘) → **"API 및 서비스" → "사용자 인증 정보(Credentials)"** 클릭.
5. 위쪽 **"+ 사용자 인증 정보 만들기" → "API 키"** 클릭.
6. 화면에 뜨는 `AIza...` 로 시작하는 긴 문자열이 API 키입니다. **복사해서 저에게(Claude) 전달**해 주세요.
   - 키는 비밀번호처럼 다뤄 주세요. 채팅에 붙여넣으면 제가 실행 후 폐기(키 삭제) 방법도 안내해 드립니다.

## 2단계 — 음원 생성 (Claude가 실행)

키를 받으면 제가 아래를 순서대로 실행합니다:

```
node tools/import.mjs                     # 문항 ID 매핑 생성
GOOGLE_TTS_KEY=<키> node tools/tts-batch.mjs   # MP3 생성 (미·영·호 성우, 속도 -5%)
```

- 산출물: `tools/out/audio/` 폴더의 MP3 + `audio-manifest.json`
- 대화(L3)는 여자/남자 성우를 줄마다 바꿔 합성하고, L2는 질문+보기 4개를 한 트랙으로 만듭니다.

## 3단계 — R2 업로드·연결 (Claude가 실행)

1. Cloudflare R2 버킷 `jumplish-assets` 생성 → MP3 업로드
2. 버킷에 공개 도메인 연결 (Cloudflare 대시보드에서 R2 → 버킷 → Settings → Public access)
3. `R2_PUBLIC_BASE=<공개 주소> node tools/import.mjs` → seed 재적용 → 앱에서 음원 재생 확인

## 자주 묻는 것

- **왜 실시간으로 안 만들고 미리 만드나요?** 학생이 들을 때마다 TTS를 호출하면 비용이 계속 나갑니다.
  미리 만들어 두면 몇 만 명이 들어도 추가 비용이 0원입니다.
- **성우 품질은?** Google 뉴럴 보이스(미국·영국·호주 원어민 톤)를 사용합니다. 전량 생성 후
  1~2시간 정도 전수 청취 검수를 권장합니다(체크리스트: content-pipeline.md 4절).
- **키가 유출되면?** 콘솔 → 사용자 인증 정보에서 해당 키를 삭제하면 즉시 무효화됩니다.
