# 점프리시 테스터 안내 (지인 자녀 실사용 검증)

> 대상: 초등 3학년 ~ 중학교 3학년 · 기간: **2주** · 하루 **10~15분**
> 목적은 "우리 아이 성적 올리기"가 아니라 **어디서 막히는지 보는 것**입니다.
> 아이가 못 푸는 게 아니라 앱이 잘못 만든 것을 찾는 게 이 2주의 목표입니다.

---

## 1. 운영자용 준비 체크리스트

- [ ] 테스터 계정 발급 (`node tools/make-testers.mjs 8 JT`) — **아이 한 명에 계정 하나**
- [ ] 발급한 SQL을 운영 DB에 적용
- [ ] 아이디·비밀번호를 부모님께 개별 전달 (단체방에 뿌리지 않기)
- [ ] 아래 3장 안내문을 그대로 복사해 부모님께 전달
- [ ] 2주 뒤 신고 내역·기록 확인 → 계정 정리

**왜 하루 12문항인가**: 지금 문항이 120개라 12문항 반이라야 2주 동안 같은 문제가
겹치지 않습니다. 20문항 반은 14일 중 6일이 문항 부족으로 정원 미달입니다
(`node tools/simulate-fortnight.mjs 14 20` 으로 확인 가능).

---

## 2. 2주 동안 우리가 알아내려는 것

| 질문 | 어떻게 확인 |
|---|---|
| 아이 혼자 로그인해서 끝까지 가는가 | 첫날 부모님 관찰 메모 |
| 진단 테스트가 너무 길거나 어렵지 않은가 | 중간에 그만두는지 |
| 해설을 읽고 "아 그렇구나" 하는가 | 앱 안 신고 `무슨 말인지 모르겠어요` 건수 |
| 듣기 속도가 적당한가 | 신고 `소리가 안 들려요` 건수 |
| 사진이 문제와 맞는가 | 신고 `사진이 문제랑 안 맞아요` 건수 |
| 며칠째에 흥미가 떨어지는가 | 접속이 끊긴 날 |

아이가 앱 안에서 **"이 문제, 이상해요"** 를 누르면 위 항목이 그대로 쌓입니다.
부모님이 대신 옮겨 적으면 진짜 이유가 사라지니, **아이가 직접 누르게** 해 주세요.

## 4. 아이가 처음 켰을 때 (부모님이 옆에서 볼 것)

1. 로그인 화면에서 **아이디는 대소문자를 가리지 않습니다** (`jt-1` 도 됩니다)
2. 처음엔 **실력 진단**부터 뜹니다 — 중간에 끄면 처음부터 다시 해야 합니다
3. 듣기 문제는 **소리가 자동으로 한 번** 나옵니다. 이어폰을 권합니다
4. 답을 고른 뒤 **'선택 확정'** 을 눌러야 채점됩니다 (잘못 눌러도 확정 전이면 바꿀 수 있습니다)
5. 채점 뒤에 노란색으로 칠해진 부분이 **답의 근거**입니다

## 5. 2주가 끝나면

- 신고 내역 확인: `SELECT kind, COUNT(*) FROM feedback GROUP BY kind ORDER BY 2 DESC;`
- 아이별 진행: `SELECT user_id, COUNT(DISTINCT date(answered_at,'+9 hours')) FROM answers GROUP BY 1;`
- 계정 정리: 테스터 계정과 기록 삭제 (안내문에 지운다고 적었으므로 **반드시 지웁니다**)
