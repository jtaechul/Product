# 규칙 초안 (사장님 컨펌 전 — CLAUDE.md에는 아직 넣지 않음)

## 오늘 사고 원인
1. 아리아 편: 원본의 개그 포인트(해머가 심판을 맞힘)를 영상 AI가 거부할까 봐 내가 "공이 옆으로 날아감"으로 순화 → 개그가 사라짐.
2. 물티슈 편: 사장님이 새로 올린 원본(드럼통·넘어짐)을 다시 분석하지 않고 예전 원본 분석(드럼통·넘어짐 없음)을 그대로 씀 → 넘어지는 장면이 화면에 안 나옴.
3. 물티슈 편: 스토리보드 정지 칸(그림)과 새로 만든 영상을 섞음 → 옷·개 모습이 장면마다 달라짐. 지시에 'hand'가 남아 사람 손이 나옴.

## 넣을 규칙 문장(초안)
- 개그 포인트는 절대 빼지 않는다. 막힐 것 같으면 맞는 부위·표현만 바꾸고(사타구니 → 엉덩이) 맞는 동작은 남긴다. 돈 쓰기 전 자동 점검(`_remake_preflight`)이 개그 누락·비켜 가기 순화를 잡으면 멈춘다.
- 원본이 바뀌면 0.5초 분석을 반드시 새로 한다(원본 지문 `src_sig`로 자동 확인).
- 정지·줌 개그는 만든 영상의 한 장면을 멈춰 부드럽게 줌(`freeze_from`, `zoom`) — 스토리보드 그림을 영상 사이에 섞지 않는다.
- 영상은 한 편에 한 번만 만들고(컷은 지시문에 초 단위로) 잘라 쓴다(`cut_from`). 여러 번 만들면 점검이 멈춘다.
- 손이 나오는 장면은 'furry dog paw'로만 쓴다('hand'·'finger'가 있으면 점검이 멈춘다).
- 돈 안 드는 점검만 하는 요청: `remake.mode: "check"` — 돈 드는 호출은 코드에서 막힌다.

## 추가 초안 — 동작 따라 만들기(Genjutsu 방식, 사용자 지시 2026-10 "모든 포인트 살리고 최대한 유사하게")
- 새 리메이크 기본 방식 = `remake.method: "motion"`: 원본 영상은 **동작·카메라·타이밍 참고**로만 넣고(원본 위 합성 아님), 모습은 확인받은 **깨끗한 스토리보드 1번 칸**에서 가져와 9:16으로 새로 렌더링(`_remake_motion`, Omni `reference_to_video`). 영상은 한 편에 **한 번만**.
- 순서: 원본 0.5초 시간표(약 0.01달러) → 개그 포인트 자동 추출(맞힘·넘어짐·줌·정지·입에 넣기) → 스토리보드 6칸(개그 시각 우선, 원본 합성 없이 새로, 약 0.15달러) → **사장님 확인** → 영상 1번(10초 약 1달러) → 줌·정지는 조립 때 같은 시각에 직접(`_apply_gag_fx`, 줌 효과음 자동) → 원본 소리 유지.
- 돈 쓰기 전 사전 점검(`_remake_preflight`)에서 개그 포인트 누락·막힐 낱말·사람 손·옛 원본 분석을 잡으면 멈춤. 거절(400)은 요금 없음으로 되돌리고, 실제 인물 거절만 얼굴 가려 한 번 더. 그래도 안 되면 멈추고 보고(자동으로 다른 방식으로 돈 쓰지 않음).

## 추가 초안 — AI 시간표는 프레임으로 검증(2026-10 사과 도둑 편)
- AI가 만든 0.5초 시간표가 틀릴 수 있다(사과 도둑 편: 실제로는 개가 쓰다듬음을 받고 가만히 보는데 "개가 덤벼들어 도둑이 도망"으로 읽음). 돈 쓰기 전에 원본을 0.25~0.5초 간격 프레임으로 뽑아 시간표와 대조하고, 틀리면 확인한 시간표를 `remake.timeline`(목록)으로 직접 넣는다. 개그 포인트(`remake.gags`)도 확인한 것으로 적는다.
- 원본에 창작자 워터마크·검은 화면·아웃트로가 있으면 `window`로 잘라 본편에서 뺀다(사과 도둑 편: 8.2초 뒤 검은 화면+인스타 로고).

## 추가 초안 — 바꿀 대상·위아래 이어 그리기(사장님 지적 2026-10-09 타일매트 편)
사고: 분석 지시문이 '항상 사람을 시바견으로'로 고정돼 주인(여자)이 시바견이 되고 미끄러지는 강아지 두 마리는 그대로. 관리자 화면엔 무엇을 바꿀지 안 보였음.
스토리보드 아래 1/3이 하얗게 날아간 빈 바닥(밝기 210, 무늬 없음)인데 기존 검사(흐림 띠만)가 통과시킴.
- (사장님이 원하는 것 10) 원본에 동물이 나오면 **동물만 시바견, 사람(주인)은 사람 그대로**. 동물이 없을 때만 사람의 머리·팔다리를 시바견으로.
- (리메이크 줄) ⛔ 바꿀 대상: 분석(`TREND_ASK`)이 위 규칙으로 정하고 관리자 화면에 '바꿀 것'을 한국어로 보여 준다(`swap_ko`). 제작 쪽도 0.5초 시간표에 동물이 나오는데 사람을 바꾸게 돼 있으면 자동으로 바로잡는다(`_has_animals`, log `swap_fixed`).
- (9:16 줄) 위아래 이어 그리기는 같은 장소의 진짜 모습으로: 위 = 벽·천장, 아래 = 카메라 쪽으로 커지는 바닥(타일 줄눈·반사·그림자), 밝기·색·선명도는 가운데와 같게. 하얗게 날아간 빈 바닥·회색·흐림 띠는 스토리보드 검사(`_panel_bands` painted)에서 멈추고 보여 주지 않는다.
- (9:16 줄, 2026-10-09 두 번째 지적: "광활하게 작게 그리면 안 보인다, 720p 돈 주고 360p만도 못하다") 가로 원본은 위아래를 이어 그리지 않고 **움직임을 따라가는 세로 화면**으로 잘라 키운 뒤 720p로 합성한다(`_track_crop`, 무료). 위아래 띠가 원천적으로 없고 강아지가 약 3배 크게 담긴다. 이어 그리기는 사장님이 시킬 때만(`vertical: "extend"`).
  - 카메라는 AI가 찾은 위치로 **동물을 먼저** 따라간다(동물 없으면 사람). 움직임만 보면 방을 나가는 주인을 따라가 강아지를 놓친다(2026-10-09 6번 칸).
